## 🆘 Troubleshooting

### "Nothing happens when I click the button"
- Check browser console (F12) for errors
- Make sure backend is running: `npm run dev`
- Verify `.env` file has all credentials

### "Health endpoint shows errors"
```bash
curl http://localhost:3000/api/health
```
Should return `"status": "healthy"`

### "Identity verification failed"
- Make sure you're using sandbox SSN starting with 666
- Check CRS credentials in `.env`

### "AI Ranger message doesn't update"
- Check Gemini API key in `.env`
- Look for errors in console
- Gemini API might have rate limits (free tier)
